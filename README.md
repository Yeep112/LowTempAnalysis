# 低溫量測分析工具（Low-Temperature Analysis）

把 `Analysis.ipynb` 裡的分析整理成一個可以重複使用的工具，有兩種用法：

- **分析介面**（選單 1）：開啟 .db 後一次讀進所有 run，分成「1D 資料分析」「2D 資料分析」兩頁，選 run、選功能、調參數，圖馬上更新。
- **批次分析**（選單 4、5）：參數寫在 `jobs\*.toml`，一次重新產生某個樣品的所有圖和 `index.html`。

不需要安裝 qcodes（直接讀 .db），也不會修改原始資料。

```
LowTempAnalysis\
├─ install.bat           ← 第一次雙擊，安裝成軟體（開始功能表 + 桌面圖示）
├─ run_analysis.bat      ← 開啟軟體（可複製到任何地方）
├─ tools.bat             ← 文字選單（批次分析、資料總表等）
├─ publish.bat           ← 開發者用：一鍵發佈到 GitHub（同事會收到更新）
├─ lta_env.bat           ← 尋找 Python（給上面的啟動檔用）
├─ release.json          ← 版本號與 GitHub 更新來源
├─ 發佈與更新.md          ← 透過 GitHub 發佈新版、讓其他人自動更新
├─ settings.toml         ← 這台電腦的設定（第一次開啟時由 settings.example.toml 自動建立）
├─ 擴充指南.md            ← 之後要加功能、新量測方式時看這份
├─ jobs\                 ← 批次分析設定檔（每個樣品一個）
├─ lta\                  ← 程式本體（Python 原始檔，可以直接改）
│   ├─ core\             資料層：讀 .db、量測模式（I→V、V→I）
│   ├─ analysis1d\       1D 分析功能（一個功能一個檔案）
│   ├─ analysis2d\       2D 分析功能
│   ├─ gui\              分析介面
│   └─ batch\            批次分析
├─ assets\               ← 圖示（icon.svg 原稿、icon.ico、各尺寸 png）
├─ Explore.ipynb         ← 在 Jupyter 自由探索、測試新功能
└─ catalog.xlsx          ← 「更新資料總表」產生的所有 run 一覽
```

## 第一次使用

1. 把整個資料夾**解壓縮**到固定位置，例如 `D:\Yeep\02 Low Temperature Analysis\`（不要在 zip 裡直接執行）。
2. **雙擊 `install.bat`（只要做一次）**：會在「開始」功能表和桌面加上「低溫量測分析」。之後就像一般軟體一樣，從開始功能表搜尋或雙擊桌面圖示開啟，不會有黑色視窗，也可以釘選到工作列。
3. 第一次開啟後，到 **⚙ 設定 → 資料與輸出** 選擇放樣品資料的資料夾。

三個啟動檔：

| 檔案 | 用途 |
|---|---|
| `run_analysis.bat` | 開啟軟體（黑色視窗會馬上關掉，軟體獨立執行）。可以複製到任何地方使用；把 .db 拖上去會直接用它開啟 |
| `tools.bat` | 文字選單：批次分析、資料總表、建立批次設定檔…（軟體裡的「▾ 工具」也有同樣的功能） |
| `install.bat` | 建立開始功能表與桌面捷徑 |
| `LowTempAnalysis.pyw` | 直接開啟軟體（不會有黑色視窗）。工作列釘選的圖示執行的就是它 |

需要的 Python 套件：numpy、scipy、matplotlib、tkinter（Anaconda 都內建）。啟動檔會自動尋找電腦上的 Python（Anaconda、Miniconda、python.org…）並檢查套件；找不到時會說明原因，並可以自動安裝。

**自動更新**：軟體開啟時會到 GitHub 檢查新版本，有的話跳出提示，按「是」就自動更新並重新開啟（設定與資料不會被覆蓋）。發佈方式請看 **`發佈與更新.md`**。

## 分析介面

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ◢ 低溫量測分析   資料庫 [樣品 › xxx.db ▼]  [開啟檔案] [重新整理] ☑量測中自動更新 │
├────────────────┬──────────────────────────┬─────────────────────────────────┤
│[1D 資料分析][2D]│ ☰ 資料            3/122 已選│ ∂ 微分 dV/dI · dI/dV   [13 筆][I→V]│
│                │ ⌕ [T_1.6K  104-116      ] │ 工具列                            │
│ 分析功能        │ run 量測  T   點數  描述    │                                  │
│  基本           │ 116 I→V 1.6 1001 ...      │          圖                       │
│  ∿ 曲線         │  9  V→I  -   201 ...      │  （滑鼠移上去顯示數值）             │
│  ∂ 微分         │──────────────────────────│                                  │
│  ⇅ 曲線+微分    │ ∂ 參數            [恢復預設]│                                  │
│  進階           │ 微分方法 [相鄰點差分 ▼]     │                                  │
│  Ω 電阻         │ ...                       ├─────────────────────────────────┤
│  ⟋ 線性化       │ 圖例 / 顏色 / 排序          │ ≡ 文字結果                        │
│  ◆ 轉折點       │ [▶ 繪圖][存圖][CSV][新視窗] │                                  │
└────────────────┴──────────────────────────┴─────────────────────────────────┘
```

- 左上切換 **1D / 2D**，整個介面的主色會跟著換（1D 藍、2D 紫），清單只顯示該類資料。
- 左欄是**功能卡片**，依「基本 / 進階」「色圖 / 萃取」分組。不支援目前所選資料的功能會變淡（例如選了 V→I 資料，轉折點分析就會變淡）。
- 中欄上方是 run 清單，「量測」欄顯示量測方式：`I→V`（藍）、`V→I`（綠）、`B⊥×I→V`（紫）。
- 開啟資料庫後會在背景把所有 run 讀進記憶體，之後切換、多選都很快。
- 量測進行中勾「自動更新」，新的 run 會自動出現（每 10 秒檢查一次）；也可以按 F5。
- 篩選欄：輸入文字（比對實驗描述與量測方式，例如 `T_1.6K`、`I+_38`、`V→I`），或 run 範圍 `104-116`；多個條件用空白分開。點欄位標題可以排序。
- 2D 色圖：**左鍵點色圖會在右邊加一條該位置的切線，右鍵清除**。
- 「存圖」「CSV」預設存到 `{.db 所在資料夾}\01 Figure\gui\`；「新視窗」會把目前的圖複製出來並排比較。
- **⚙ 設定**（右上角）：介面配色（5 組預設或自訂 HEX / RGB，重新開啟後套用）、預設的數據顏色循環、資料夾與輸出格式（寫回 `settings.toml`）、建立 / 修復捷徑、複製啟動檔到桌面。
- **數據顏色**：在 run 清單選取後按右鍵（或「● 顏色」按鈕）→ 用色盤選、輸入 HEX（`#e4572e`）或 RGB（`228, 87, 46`），也可以「依溫度套用兩色漸層」。設定過顏色的 run 在清單上會以該顏色顯示，存在樣品資料夾，下次開啟還在。
- **工具列的 Home（⌂）**：回到剛畫好時的範圍，並讓圖剛好填滿可見區域。
- **圖表樣式列**（圖的上方）：勾選格線、調整 X / Y 軸標籤、色條標籤、刻度、圖例、標題的字體大小。改了立刻套用、不重新計算，存圖也會照這個樣式，設定會記住。
- **逐筆設定**（例如線性化 dV/dI）：參數區下方會列出每一筆選取的 run，可以個別設定負側 / 正側 edge、平移、內插修補區間（例如 `-505:-495, 300:310`，把這些電流範圍的尖峰換成直線內插）。雙擊格子修改，清空 = 用預設；也可以直接在圖上拖曳 ▼ 標記（多筆）或藍 / 綠虛線（單筆）調整 edge。設定存在 `{.db 所在資料夾}\01 Figure\gui\per_run_settings.json`，下次開啟還在。

### 1D 功能

| 分組 | 功能 | 支援 |
|---|---|---|
| 基本 | 曲線（IV / VI） | 所有量測方式 |
| 基本 | 微分 dV/dI · dI/dV（相鄰點差分或 Savitzky-Golay，可 log、可取倒數） | 所有 |
| 基本 | 曲線 + 微分 上下對照 | 所有 |
| 進階 | 電阻 R（直線擬合）vs T | I→V、V→I |
| 進階 | 線性化 dV/dI（兩側直線取代雜訊；每筆可個別設定 edge、平移、修補區間，可在圖上拖曳） | I→V |
| 進階 | 轉折點追蹤 + I vs T（log dV/dI 台階；紅點可拖曳修改） | I→V |
| 進階 | Ic vs T 擬合（power law / AB / KO / GL / KL / SNS，四個階段） | I→V |
| 進階 | IV 轉折點 + Ic vs T（二次微分） | I→V |

#### 轉折點追蹤 + I vs T

- 左邊是 log10(dV/dI) 溫度疊圖加紅點，右邊是轉折電流 I vs T（同一類轉折正負兩條同色，實心 = 正電流、空心 = 負電流）。
- 和「線性化 dV/dI」共用 edge、平移、修補區間：在任一頁改，另一頁就跟著變。
- **修改紅點**：
  - 疊圖上左右拖曳紅點，或在 I vs T 上上下拖曳；
  - 空心灰點 = 那個溫度沒找到，拖到正確位置就補上一點；
  - 右鍵紅點 → 刪除（這筆不畫）或恢復自動偵測；
  - 也可以直接改逐筆設定表的「手動轉折點」，例如 `inner + = 430; center - = none`。
  手動改過的點畫成 ◆，結果表格會標 ＊。
- 轉折線設定在參數區的多行文字框，一行一條：`名稱 | 猜測 | 搜尋寬 | 門檻 | 其他`，預設就是原本 notebook 的 `TRANSITION_LINES`。
- 參數值（包括轉折線設定）會依資料庫各自記住，下次開同一個資料庫會還原；「恢復預設」可以清掉。

#### IV 轉折點 + Ic vs T（二次微分）

- 「顯示」可切換：IV + 轉折位置 + Ic、轉折位置 + Ic、只有轉折位置、只有 Ic、只有 IV。
- notebook（Ic_T_analysis Cell 3）的高溫規則：**找不到的轉折位置視為 0**、**強制 Ic = 0**（例 `inner: 2.6`）、
  **沒有轉折的溫度**（例 `3.8`）。這三個設定和「Ic vs T 擬合」共用。
- 同一溫度選了多筆（例如 2.8 K 的 run 103 與 104）時，結果文字會提醒；notebook 用的是 103。

#### Ic vs T 擬合

- 「轉折點來源」可選「log dV/dI 台階（轉折點追蹤）」或「IV 二次微分」，都用該頁的設定（含手動改過的紅點），Ic = 正側 − 負側（mA）。
- 也可以改從 CSV 讀（上一頁匯出的 `transitions.csv`）。
- 「顯示」可切換：最終圖、轉折位置 + Ic、Stage 1–4 各自的圖、全部階段格狀總覽。
- 結果文字是所有擬合的總表（依 R² 排序），參數貼在擬合邊界、AB 的 Tc 高於實際歸零溫度等狀況都會警告。
- 「額外 Ic = 0 的溫度」用來給 Tc 上限（例如 3.1 K 已經沒有超導但沒選到那筆）。
- 批次分析：在 `dvdi_vs_T` 加一段 `[job.ic_fit]` 就會一起擬合，範例在 `jobs\quad_002.toml`。

### 外加條件：⊗ 磁場 / ⚡ 電場 / ○ 無外加

左邊「1D / 2D」下面有一排「外加條件」，軟體會依每筆資料的掃描軸自動分類：

| 分類 | 怎麼判斷 | 例子 |
|---|---|---|
| ⊗ 磁場 | 掃描軸是 `*_field`（單位 T） | IV vs By |
| ⚡ 電場 | 掃描軸是閘極電壓（`appl_TG`、`appl_BG`、`gate`、`Vg`… 單位 V） | IV vs TG |
| ○ 無外加 | 沒有磁場、閘極掃描 | 不同溫度的 IV |

- 選「全部」：所有資料與功能都列出來，功能依分類分組；選一筆資料時，不適用的功能會變淡。
- 選某一類：資料清單與功能清單都只留那一類（每個分類旁的數字是筆數）。
- 選到不適用的資料時會自動換成同一種功能的對應版本（例如「切換電流 Ic vs B」↔「Ic vs Vg」）。
- 只適用磁場的參數（B₀ 平移等）在閘極資料上會自動隱藏。
- **閘極是底部或頂部**：分類下面「⚡ 閘極：appl_TG = V_bottom　✎ 修改」點一下就能改成 V_top 或一般 Vg；
  圖上的軸標籤（V$_\mathrm{bottom}$ / V$_\mathrm{top}$）會跟著變。設定存在每個資料庫；
  勾「其他資料庫也預設這樣設定」會變成預設值。沒設定時一律當作 **V_bottom**。

### 2D 功能

| 分組 | 功能 | 支援 |
|---|---|---|
| ▦ 色圖（磁場、電場都適用） | 色圖（量測值）+ 點擊切線 | 任何 2D |
| ▦ 色圖 | 色圖（微分 dZ/dF）+ 點擊切線（可平滑、去掉掃描頭尾的假尖峰） | 任何 2D |
| ⊗ 磁場 B | 切換電流 Ic vs B（磁場） | 快軸施加電流、量電壓 |
| ⊗ 磁場 B | 指定位置切線 + 轉折點（沒有剛好的位置就用最近的資料） | 同上 |
| ⚡ 電場（閘極 Vg） | Ic vs Vg（切換電流）：每個 Vg 找 dV/dI 峰值（或電壓門檻） | 同上 |
| ⚡ 電場（閘極 Vg） | R vs Vg（電阻）：零偏壓 R₀、高偏壓 R_N、R₀/R_N，可切換電導 | 同上 |
| ⚡ 電場（閘極 Vg） | 指定 Vg 的 IV 疊圖（IV 與 dV/dI） | 任何 2D 閘極資料 |

## 設定檔寫法（jobs\*.toml）

```toml
db = 'quad_002_2026-11-14_01.db'      # 完整路徑，或只寫檔名（自動在 data_root 底下找）

[defaults]                             # 所有 job 共用
voltage = "meas_voltage_K2"

[[job]]                                # 每個 [[job]] 是一個分析
name = "dVdI_vs_T_log"                 # 輸出資料夾名稱
type = "dvdi_vs_T"                     # 分析種類（見下表）
scale = "log"
edges = [[1.6, -870, 950], [2.8, -666, 718]]   # 依溫度內插

  [job.select]                         # 自動挑 run（放在 job 的最後面！）
  contacts = "I+_38, V+_39, V-_40, I-_41"
  T_range = [1.6, 2.8]
  duplicates = "latest"
```

**挑 run 的兩種方式**

- `runs = [116, 115, 114]`：直接指定。
- `[job.select]`：依條件自動挑，**之後新量的資料只要符合條件就會自動加進去**。可用的條件：

| 條件 | 說明 |
|---|---|
| `kind` | qcodes 實驗名稱，例如 `"IV"`、`"IV vs By"` |
| `contacts` | 接點，例如 `"I+_38, V+_39, V-_40, I-_41"`（從實驗描述自動解析） |
| `T_range` | 溫度範圍 `[1.6, 2.8]`（從描述的 `T_1.6K` 解析，也支援 `T_37mK`） |
| `run_range` | run 編號範圍 `[104, 116]` |
| `sweep` | `"I-->I+"`、`"I+->I-"`，或 `"none"` = 描述裡沒有標掃描方向的 |
| `field_axis` | `"y_field"` 等 |
| `name_contains` | 描述必須包含的文字（可以是 list） |
| `exclude` | 排除的 run，例如 `[103]` |
| `duplicates` | 同一溫度有多筆時：`"all"`（預設）、`"latest"`、`"first"` |

> ⚠️ TOML 的規則：`[job.select]` 下面的設定都會被算進 select，所以它要放在該 job 的**最後面**。放錯時工具會提醒你。

**依溫度變化的參數**：`edges`、轉折線的 `guess_uA`、`search_uA` 都可以寫成 `[[T, 值], ...]` 的表，表上沒有的溫度會自動線性內插，所以新加的溫度不必一一補參數。

其他共用選項：`labels = { "104" = "2.8 K (2nd)" }` 覆寫圖例；`temperatures = { "64" = 1.2 }` 補上描述裡沒有寫的溫度；`enabled = false` 暫時不跑；`xlim`、`ylim`。

## 分析種類與參數

括號內是預設值。

**`iv`**：IV 曲線
`x_unit`（"uA"／"mA"）、`individual`（true，存個別圖）、`overlay`（多筆時為 true）、`offset_mV`（0，疊圖平移）、`export_csv`（false）

**`dvdi`**：原始 dV/dI
`merge_duplicates`（true，同電流取平均）、`offset_ohm`（0）

## 介面小技巧

- **介面大小**：⚙ 設定 → 外觀 →「介面大小」，預設「自動」會依螢幕解析度與 Windows 縮放判斷
  （例如 4K 但 Windows 用 100% → 150%；小筆電 → 90%），也可以手動選 80%–175%。文字、欄寬、分隔線、圖會一起縮放。
- **介面顏色**：⚙ 設定 → 外觀，點一個顏色圓點就立刻套用（不用重開，資料和選取都保留）。也可以輸入任何 HEX / RGB：
  淺色當背景、較深或飽和的顏色當主色、很深的顏色自動切成深色版面。1D / 2D 主色可以另外指定。
- **版本**：標題列「Low-Temperature Analysis」旁邊顯示目前版本；有新版時會變成「→ vX 可更新」，點它看更新內容。
- **多張圖**（例如色圖 + 切線、轉折點的兩張圖、Ic 的格狀總覽）：每張圖保持最小尺寸，放不下就出現捲軸
  （滾輪上下、Shift + 滾輪左右）。圖表樣式第二列可選「左右並排 / 上下排列 / 縮放填滿視窗」，並設定每張的最小寬高。
- **圖的大小**：圖表樣式第二列「圖的大小」選「固定大小」，再設定寬 / 高（像素）。圖不會被拉伸或壓縮，
  比視窗大就出現捲軸；「用目前大小」會把現在看到的大小填進去。存圖也是這個比例。
- **2D 切線**：左鍵點色圖 → 在那個位置加切線（右邊畫 IV）；在已有的切線上**按住**（或按住拖曳）→ 把它移到別的位置，
  右邊的 IV 跟著更新；右鍵清除全部。切線位置會依資料庫、功能、run 記住，改參數重畫或重開軟體都會回到原位。
- **存圖大小**（參數區下方）：可以和畫面上看到的大小分開。選「8.5 × 6 cm（論文單欄）」「17 × 12 cm（雙欄）」或「自訂大小…」，
  之後按 ⬇ 存圖 / Ctrl+S 都用這個大小；字體（預設軸標籤 8 pt）與線條會等比例縮小，畫面上的圖不受影響。
  「⚙ 存圖設定」（或 Ctrl+Shift+S）可改寬、高、字體，按「確定並存圖」直接存；選「同畫面大小」就跟以前一樣。
- **記住上次的畫面**：每個資料庫各自記住上次的 1D / 2D、每頁選的功能、選的 run 與篩選；重新開啟同一個 .db 會自動回到那裡
  （⚙ 設定裡可關閉「開啟資料庫時回到上次的畫面」）。
- **工作列圖示**：開啟軟體後在工作列圖示按右鍵 →「釘選到工作列」，之後點它就直接開啟軟體。
  （v2.11 以前釘選的圖示點了沒反應，請先「從工作列取消釘選」再重新釘選一次。）
- **✎ 標題與軸標籤**：圖表樣式第二列右邊。可改整張圖的標題、每張子圖的標題與 X / Y 標籤、色條標籤；
  空白 = 自動，輸入 `-` = 不顯示，可用 `$I_c$` 這類數學式。依資料庫、分析各自記住。
- **逐筆設定**：在逐筆設定表點一列，上方會出現「✎ 正在設定：run 111 · 2.1 K」，圖上這筆變粗、其他變淡，
  文字結果裡這筆也會標色；按 Esc 取消。
- **2D 色圖**：「平移後在 0 畫虛線（B₀ 位置）」「色圖上標出切線位置」「一開始先畫一條切線」都可以取消勾選。
  操作提示（例如「左鍵點色圖加切線」）顯示在圖的上方，不會被存進圖檔。
- **Ctrl + 滾輪**：以滑鼠所在位置為中心放大 / 縮小；工具列 ⌂ 回到原本範圍，← 回上一步。
- **圖例**：點圖例裡的某一項 → 隱藏 / 顯示那條曲線（Y 範圍會跟著調整）；按住圖例拖曳 → 移到任何位置。
  兩者都依資料庫、分析記住；「✎ 標題與軸標籤 → 顯示隱藏的曲線、圖例回原位」可以全部還原。
- **背景計算**：線性化、轉折點、Ic 擬合等較慢的計算在背景執行，狀態列右邊有進度條，計算中仍可操作；
  資料多時會先畫已完成的那幾筆。參數又改了的話，舊的計算會自動取消。
- **復原 / 重做**：逐筆設定（拖曳紅點、改 edge、清除設定…）可以 Ctrl+Z 復原、Ctrl+Y 重做，逐筆設定表上方也有按鈕。
  游標在文字框裡時 Ctrl+Z 是文字框自己的復原。
- **⧉ 同溫度留一筆**（清單下方）：選取的資料裡，同一個溫度、同一組接點選到多筆時只保留一筆
  （可選保留 run 號最小 / 最大 / 點數最多），例如 2.8 K 的 run 103 與 104。
- **更新記錄**：⚙ 設定 → 更新 列出歷次版本的更新內容；同事跳過好幾版時，更新視窗會一次列出所有版本的內容。
  手動覆蓋了新檔案但還沒重開時，左上角版本標籤會變成「→ 重新開啟以套用」，點它就會重開。
- **這版新增了什麼**：更新後（或換成新版後）第一次開啟，會跳出這段期間新增的功能；
  不想看可以勾「以後更新時不要自動顯示」，或在 ⚙ 設定 → 更新 關掉。
- **「色」欄的圓點**：代表這筆有自訂顏色（右鍵 → 顏色），滑鼠移上去狀態列會顯示色碼；右鍵 → 清除顏色 可恢復自動。
- **設定檔位置**：`settings.toml`（資料夾、dpi、圖檔格式）存在 `%LOCALAPPDATA%\LowTempAnalysis\`，不在工具資料夾；
  ⚙ 設定 → 資料與輸出 可以看到位置。
- **拉動視窗、分隔線**：拖曳分隔線時只顯示一條線，放開才重新排版；圖在停下來 0.15 秒後才重畫，不會卡頓。
  分隔線位置會記住，下次開啟一樣。
- **圖中中文變方框**：⚙ 設定 → 外觀 →「圖中的中文字型」換一個；`run_analysis.bat diag` 會列出目前用的字型。

## 軟體模式的小提醒

- **回報問題**：⚙ 設定 → 更新 →「📦 打包錯誤記錄」，會把 error.log、crash.log、app.log 與環境資訊壓成一個 zip（不含量測資料），
  傳給維護者即可；命令列是 `run_analysis.bat report`。
- 程式出錯時會跳出提示，詳細記錄在 `%LOCALAPPDATA%\LowTempAnalysis\error.log`（`app.log` 是一般輸出）；
  整個視窗直接消失（閃退）時，原因會記在同一個資料夾的 `crash.log`。
- 讀取 .db 在背景進行；檔案正在被量測程式寫入或雲端同步時會自動重試，仍失敗會說明原因，原本開著的資料庫不受影響。
- 程式資料夾搬家後，重新雙擊一次 `install.bat`（或 ⚙ 設定 → 啟動與安裝 → 建立 / 修復捷徑）即可。
- 別台電腦開不起來：執行 `run_analysis.bat diag`，或看 `發佈與更新.md` 第 4 節。移除捷徑：選單或命令列執行 `python -m lta uninstall`（不會刪除程式與資料）。
- 程式仍是資料夾裡的 Python 原始檔，修改後重新開啟軟體就會生效，不需要重新安裝。
